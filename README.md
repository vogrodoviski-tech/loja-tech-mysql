# Loja Tech — Banco de Dados MySQL

## Sobre o projeto

Projeto acadêmico de banco de dados relacional desenvolvido para praticar SQL e conceitos de modelagem de dados.

O sistema simula parte do gerenciamento de uma loja de produtos de tecnologia, permitindo cadastrar clientes, produtos e vendas.

## Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL

## Funcionalidades

- Cadastro de clientes
- Cadastro de produtos e controle básico de estoque
- Registro de vendas associadas a clientes
- Relacionamento entre tabelas com chaves estrangeiras
- Consultas utilizando INNER JOIN e filtros com WHERE

## Estrutura do banco de dados

O projeto contém três tabelas principais:

- **cliente:** armazena as informações dos clientes.
- **produtos:** armazena os produtos, preços e quantidades em estoque.
- **vendas:** registra vendas e relaciona cada uma ao cliente responsável.

## Objetivo

Desenvolver conhecimentos práticos em SQL, criação e relacionamento de tabelas, integridade referencial e consultas a bancos de dados relacionais.
